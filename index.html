data-on-keys

Bind keyboard events to Datastar expressions, with key combinations, several keys per binding and timing modifiers.

                Guide
                
Usage

                
The data-on-keys attribute binds keyboard events to Datastar expressions, with key combinations and modifiers.


                
Basic syntax

                
data-on-keys[:key-spec][__modifier1][__modifier2]="action"


                
Key specifications

                
The key-spec defines which keys trigger the action. It can be:

                
    
                    
  • Single keys: space, enter, escape, tab, f1, a
    • 
                    
  • Key combinations: ctrl-k, alt-enter, shift-space, meta-s, ctrl-shift-z
    • 
                    
  • Multiple options: enter.tab, escape.f1.ctrl-q (any of these triggers)
    • 
                    
  • Any key: omit the key-spec to capture every key press
    • 
                


                
Key name mapping

                
Common aliases map to the standard JavaScript key names:

                

                    

                        
Special keys

                        
    
                            
  • space → Space character
    • 
                            
  • enter / return → Enter
    • 
                            
  • escape / esc → Escape
    • 
                            
  • tab → Tab
    • 
                            
  • backspace → Backspace
    • 
                            
  • delete / del → Delete
    • 
                        

                    

                    

                        
Navigation keys

                        
    
                            
  • up → ArrowUp
    • 
                            
  • down → ArrowDown
    • 
                            
  • left → ArrowLeft
    • 
                            
  • right → ArrowRight
    • 
                            
  • pageup → PageUp
    • 
                            
  • pagedown → PageDown
    • 
                        

                    

                

                
Function keys (f1 to f12), letter keys (a to z) and other standard keys work as expected.


                
Modifiers

                
Target

                
    
                    
  • Default: binds to window (global)
    • 
                    
  • __el: binds to the element itself (needs focus)
    • 
                

                
Behaviour

                
    
                    
  • Default: prevents the browser default (preventDefault())
    • 
                    
  • __noprevent: allows the browser default
    • 
                    
  • __stop: stops propagation (stopPropagation())
    • 
                

                
Event

                
    
                    
  • Default: triggers on keydown
    • 
                    
  • __up: triggers on keyup
    • 
                

                
Listener options

                
    
                    
  • __capture: use the capture phase
    • 
                    
  • __passive: passive listener
    • 
                    
  • __once: remove the listener after the first trigger
    • 
                


                
Timing modifiers

                
Control when and how often the expression runs:

                
    
                    
  • __delay.{time}: postpone by a fixed time, for example __delay.500ms or __delay.1s
    • 
                    
  • __debounce.{time}: wait until the keys stop. Options __leading, __notrailing, for example __debounce.300ms__leading
    • 
                    
  • __throttle.{time}: limit the rate. Options __trailing, __noleading, for example __throttle.1s__trailing
    • 
                

                
Times are given in milliseconds (ms) or seconds (s).


                
View transitions

                
    
                    
  • __viewtransition: wraps the state change in the View Transitions API, for example data-on-keys:space__viewtransition="$counter++"
    • 
                

                
Browsers without the View Transitions API ignore the modifier.


                
Common examples

                
<!-- Global shortcuts -->
<div data-on-keys:ctrl-s="saveDocument()"></div>
<div data-on-keys:escape="closeModal()"></div>

<!-- Element-specific -->
<input data-on-keys:enter__el="submitForm()">
<textarea data-on-keys:ctrl-enter__el="submit()"></textarea>

<!-- Allow default behaviour -->
<div data-on-keys:tab__noprevent="logTab()"></div>

<!-- Multiple triggers -->
<div data-on-keys:escape.f1.ctrl-h="showHelp()"></div>

<!-- Timing modifiers -->
<div data-on-keys:enter__delay.500ms="$message = 'Delayed!'"></div>
<input data-on-keys__debounce.300ms__el="$search($event.target.value)">
<div data-on-keys:space__throttle.1s="$counter++"></div>

<!-- View transitions -->
<div data-on-keys:space__viewtransition="$counter++"></div>

                Test 9
                
Timing modifiers and view transitions

                
Delay, debounce, throttle and view transitions on keyboard events.

                

                    
1. No timing modifier: data-on-keys:1

                    
Press 1 to increment immediately.

                    

                    


                    

                    
2. Delay: data-on-keys:2__delay.500ms

                    
Press 2: the counter increments after 500 ms.

                    

                        

                        

                    

                    

                    


                    

                    
3. Debounce: data-on-keys:3__debounce.500ms

                    
Press 3 several times quickly: the counter increments once, 500 ms after the last press.

                    

                        

                        

                    

                    

                    


                    

                    
4. Throttle: data-on-keys:4__throttle.500ms

                    
Hold 4: the counter increments at most once every 500 ms.

                    

                        

                        

                    

                    


                    

                    
5. View transition: data-on-keys:5__viewtransition

                    
Press 5 to increment with a view transition, where the browser supports it.

                    

                    


                    

                        
                    


                    

                        
Timing modifiers

                        
    
                            
  • Delay postpones by a fixed time: __delay.500ms or __delay.1s.
    • 
                            
  • Debounce waits until the keys stop, useful for search inputs. Supports __debounce.500ms__leading and __debounce.500ms__notrailing.
    • 
                            
  • Throttle limits the rate. Supports __throttle.500ms__trailing and __throttle.500ms__noleading.
    • 
                            
  • View transition wraps the state change in the View Transitions API.
    •
